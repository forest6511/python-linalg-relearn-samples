## 実行のしかた

**まずはファイルの中身を全部貼り付けて、上から順に実行するのがおすすめです。**

1. [`chapter06.py`](./chapter06.py) を開き、右上の **Raw** ボタンを押します。コードだけの画面になったら全選択（Windows は Ctrl+A、Mac は Cmd+A）してコピー
2. [Google Colab](https://colab.research.google.com/) の新しいセルに貼り付け
3. ▶ を押します（見つからないときは Shift+Enter でも実行できます）

ファイル冒頭に日本語フォントの設定（`!pip install matplotlib-fontja`）が入っているので、グラフの日本語も文字化けしません。この行はそのまま実行してください。
